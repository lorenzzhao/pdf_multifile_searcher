This file lists the third-party components of the program, their licenses, and how the
license conditions are met when the program is distributed. It is a summary to help with

each component.


1. How the program is distributed
---------------------------------

  - As source code and Python packages (this repository, the wheel and the sdist).
    These do NOT contain the third-party components: pip installs them separately from
    PyPI, and each of them comes with its own license files.

  - As standalone programs for Windows (installer, portable ZIP) and Linux (AppImage,
    tar.gz), built with PyInstaller. These DO contain the components of sections 2 and 3
    and follow section 5. Every package has a "licenses" folder with all license texts
    and notices, an exact version list (VERSIONS.txt) and the source code locations
    (SOURCES.txt).

All licenses listed below are compatible with the AGPL-3.0-or-later.

5. How the license conditions of the standalone programs are met
-------------------------------------------------------------------

AGPL-3.0 (the program itself)
  - licenses/LICENSE contains the license; the About dialog and --version show the
    copyright, the license, the warranty disclaimer and the source code location.
  - The complete corresponding source code, including the build scripts in packaging/,
    is the Git tag of each release, also attached to the release as a source archive.

LGPL-3.0 (Qt and Qt for Python) and LGPL-2.1 (libfuse in the AppImage runtime)
  - licenses/ contains the LGPL-3.0 and the GPL-3.0 it builds on; the AppImage also
    contains the LGPL-2.1 (licenses/appimage-runtime/).
  - The About dialog shows Qt's copyright notice and links both licenses.
  - The programs are built in folder mode, so the Qt libraries are ordinary files in the
    _internal/PySide6 folder and can be replaced with modified versions. The AppImage
    runtime can be rebuilt with a modified libfuse from its attached source code.
  - The unchanged source code of exactly the bundled versions of Qt (qtbase, qtsvg,
    qtwayland), Qt for Python (pyside-setup), the AppImage runtime and libfuse is
    attached to every GitHub release; licenses/SOURCES.txt lists the archives with
    their checksums. The versions are pinned in packaging/pins.json and
    packaging/release-constraints.txt.

Notices of permissive licenses (MIT, BSD, Apache-2.0, PSF, Unicode, zlib and others)
  - The license texts and copyright notices of every bundled component are in
    licenses/. The build (packaging/collect_licenses.py) assembles them and stops if
    any binary in a package cannot be assigned to a component with a known license, or
    if a Linux system library is under a GPL-family license.

7. History
----------

Version 1 of the program depended on PyMuPDF (AGPL-3.0 or commercial license from
Artifex Software). Version 2 no longer uses PyMuPDF. The standalone programs of version
2.0.0 lacked the notices of the Python interpreter, of several Linux system libraries
and of some Qt modules, and their release did not include the Qt source code; version
2.0.1 corrects this. Version 2.0.2 adds the notices of the code incorporated in CPython
itself (expat and libmpdec on Windows, HACL* and others on both systems).
